# WenDao 前端文案与信息密度准则

## 1. 总体原则
- 主旨：降低用户理解成本，提升用户使用体验。
- 产品气质：克制、清楚、温和，有书卷气，但不故作艰深。
- 优先级：
  1. 用户一眼看懂
  2. 用户知道下一步点哪里
  3. 页面看上去整齐、安静

## 2. 文案风格

### 2.1 允许的风格
- 可以有书面感，但必须自然。
- 可以有一点古意，但不能牺牲清楚。
- 可以简短，但不能缩到失去动作指向。

### 2.2 避免的风格
- 避免内部术语：
  - 例如 `FULLTEXT`、`VECTOR`、`HYBRID`、`OCR`、`导入`、`推理过程`
- 避免过度口语：
  - 例如 `我来帮你找`、`收下这篇`、`去看看`
- 避免功能腔：
  - 例如 `点击后即可进行...`、`当前模块支持...`
- 避免宣发腔：
  - 例如 `沉浸式`、`一站式`、`智能化`、`赋能`

## 3. 术语统一

### 3.1 当前导航与页面名称
- `AI问答`
- `原文检索`
- `对照阅读`
- `文章收藏`
- `字词记录`
- `图片识读`

### 3.2 阅读页内能力词
- `讲解此句`
- `全文讲解`
- `白话解读`
- `人物典故`
- `复习卡片`
- `阅读笔记`

### 3.3 统一替换规则
- 不再使用：`问道解疑`
  - 统一为：`AI问答`
- 不再使用：`白话疏解`
  - 统一为：`白话解读`
- 不再使用：`字词本`
  - 统一为：`字词记录`
- 不再使用：`收藏夹`
  - 统一为：`文章收藏` 或 `分组`
- 不再使用：`对照`
  - 统一为：`对照阅读`

## 4. 信息密度规则

### 4.1 首屏规则
- 首屏说明尽量控制在 `1-2` 行。
- 首屏先展示动作，不先解释系统。
- 同一首屏最多只保留 `1` 个主动作和 `2-3` 个起步选择。

### 4.2 卡片规则
- 同组卡片标题尽量接近长度。
  - 推荐：`6-8` 字
- 同组卡片说明尽量控制在 `2` 行左右。
- 卡片底部动作词尽量接近长度。
  - 推荐：`4-6` 字
- 如果卡片内容来自动态数据：
  - 标题优先固定
  - 动态内容放到说明区
  - 必要时做单行或两行截断

### 4.3 按钮规则
- 同组按钮尽量统一宽度。
- 主按钮文案：
  - 推荐 `4-6` 字
  - 动词明确
- 次级按钮文案：
  - 推荐 `4-6` 字
  - 不要解释太多

示例：
- `继续阅读`
- `打开此篇`
- `开始识读`
- `讲解此句`
- `收藏本文`
- `人物典故`

### 4.4 提示块规则
- 提示块只说一件事。
- 提示块优先说明：
  - 当前状态
  - 下一步动作
- 不把多条规则塞在同一块里。

## 5. 层级规则

### 5.1 标题层
- 负责说明“这一页是干什么的”。
- 不承担流程说明。

### 5.2 说明层
- 负责说明“我现在该怎么开始”。
- 只补足必要上下文。

### 5.3 按钮层
- 负责说明“点了以后会发生什么”。
- 不重复说明层内容。

### 5.4 空状态层
- 只保留：
  - 当前没有什么
  - 现在可以做什么
- 不写长段背景介绍。

## 6. 句子写法
- 一句只表达一件事。
- 优先短句。
- 少用串联词。
- 优先删掉这些冗词：
  - `这里`
  - `可以`
  - `就能`
  - `当前`
  - `继续进行`
  - `相关`

示例：
- 不推荐：`当前可在这里继续进行原文相关检索。`
- 推荐：`在这里查找原句、人物与典故。`

## 7. 高风险写法清单
- 看上去像后台设置项的词
- 需要先理解产品结构才能看懂的词
- 一个按钮里同时出现两层含义
- 标题像说明，说明像标题
- 卡片说明长短差距过大
- 同组按钮字数差距过大

## 8. 页面检查清单
每次新增或修改页面文案时，检查以下项目：

1. 用户是否一眼知道页面用途？
2. 用户是否一眼知道第一步点哪里？
3. 首屏说明是否超过 2 行？
4. 同组卡片标题是否长度接近？
5. 同组按钮是否长度接近？
6. 是否还残留内部术语？
7. 是否有过度口语化表达？
8. 空状态是否只说明状态与下一步？

## 9. 当前推荐模板

### 页面头部
- 标签：`4-6` 字
- 标题：`10-16` 字
- 说明：`1` 句

### 起步卡
- 标签：`4` 字左右
- 标题：`6-8` 字
- 说明：`2` 行内
- 动作：`4-6` 字

### 次级按钮
- 文案：`4-6` 字
- 同组宽度尽量统一

### 空状态
- 第一行：当前状态
- 第二行：下一步动作

## 10. 执行标准
- 能不用专业词，就不用专业词。
- 能不用口头词，就不用口头词。
- 能用一个动作说清，就不要写成一句解释。
- 优先让页面“易扫读”，再让页面“有气质”。
