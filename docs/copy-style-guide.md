# WenDao 前端文案最终规范清单

## 1. 总体风格
- 总体气质：古韵轻语、现代直白、克制雅正。
- 原则：有古意，不故作高深；有书面感，不失可读性。
- 避免：术语堆砌、宣传口吻、过强口语化、系统报错腔。

## 2. 语义层级
### 标签层
- 要求：短、稳、四字优先。
- 推荐词：`开卷导读`、`开卷总览`、`寻章摘句`、`问道解疑`、`拍页即读`。
- 用法：只点题，不解释。

### 标题层
- 要求：承担主叙事，一眼说明页面核心价值。
- 风格：短句为主，可略带古意，但不要抽象。
- 示例：`先把古籍翻开，一句一句通晓其义`。

### 说明层
- 要求：解释路径、补足上下文，不与标题争抢信息。
- 风格：一句话说清用途与下一步，不展开赘述。

### 按钮层
- 要求：短于说明层，强于说明层，动词明确。
- 优先词：`转至`、`翻开`、`续读`、`起读`。
- 避免：`去看看`、`开始一下`、`打开后即可查看` 这类松散表达。

### 空状态层
- 要求：最克制，只交代状态与可做动作。
- 起首词优先级：`尚无` > `暂未` > `当前`。
- 示例：`尚无阅读记录，可先自下方择一篇翻开。`

## 3. 核心术语边界
- `问道解疑`：问答页总定位。
- `义理辨析`：篇章层面的解释、分析、梳理。
- `开卷导读`：进入阅读前的引导。
- `开卷总览`：入口总览、模块总览。
- `寻章摘句`：检索原文、人物、典故、片段。
- `白话疏解`：对白话转述与说明；替代 `白话译` 的泛化表达。
- `释义` / `典故`：字词层信息，不与篇章层能力词混用。

## 4. 动词规范
### 阅读动作词
- 优先：`翻开`、`续读`、`通读`、`参照`。
- 慎用：`打开`、`开始`、`进入`。
- 说明：
  - 与古籍正文相关，优先用 `翻开`。
  - 与流程跳转相关，优先用 `转至`。
  - 与继续学习相关，优先用 `续读` / `转至续读`。

### 跳转动作词
- 优先：`转至`。
- 示例：`转至问道解疑`、`转至对照`、`转至字词本`、`转至阅读页`。

## 5. 句法与节奏
- 一句只做一件事。
- 标题可两段式，说明句尽量单句完成。
- 优先删去这些冗字：`这里`、`可以`、`就能`、`都会`、`慢慢`、`一下`。
- 若前一层已说明上下文，后一层不再重复。

## 6. 错误与反馈
- 错误提示：说明状态 + 提供下一步。
- 例：`上传未成，请检查图片格式后再试。`
- 避免：`失败，请重试`、`系统异常` 这类泛句。

## 7. 加载与处理中
- 用词要简，不要系统化。
- 优先：`正在整理阅读进度...`、`正在整理书目...`、`正在上传图片`。
- 避免过多技术词直接暴露给用户。

## 8. 后续新增页面时的检查清单
新增或修改页面时，逐条检查：
1. 是否先有四字标签，再有主标题？
2. 标题是否承担主叙事，而不是说明句？
3. 说明句是否比标题更平、更短？
4. 按钮是否比说明句更短、更硬？
5. 空状态是否使用 `尚无 / 暂未 / 当前` 体系？
6. 是否误把 `释义 / 典故 / 白话疏解 / 义理辨析` 混用？
7. 是否出现 `打开 / 开始 / 去看看 / 就能` 等可继续收紧的表达？

## 9. 当前建议的默认模板
- 标签：四字短语
- 标题：一句主叙事
- 说明：一句用途/路径说明
- CTA：`转至...` / `翻开...`
- 空状态：`尚无...，可先...`
