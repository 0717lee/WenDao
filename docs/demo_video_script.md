### 提炼的共性脚本模式

```
┌─ 第一幕：痛点引入 ─────────── 30-60s ───┐
│  背景数据/问话引出 → 痛点可视化 → 核心价值一句话  │
├─ 第二幕：方案概览 ─────────── 30-60s ───┤
│  系统架构图 → 技术栈一览 → 功能模块列表            │
├─ 第三幕：功能演示 ─────────── 3-5 min ──┤
│  场景化（用户视角）→ 2-4 条核心链路 → 逐一操作      │
├─ 第四幕：技术创新亮点 ────── 1-2 min ──┤
│  核心算法/架构/AI 模型 → 降级保障 → 测试覆盖        │
├─ 第五幕：价值总结 ─────────── 30-60s ───┤
│  社会意义 → 应用前景 → 感谢词                      │
└──────────────────────────────────────────┘
```

## 制作建议

### 视觉风格

| 要素 | 建议 |
|------|------|
| 主色调 | 古风暖色系：宣纸白 `#F5F0E8` + 墨色 `#2C2C2C` + 点缀朱红 `#C41E3A` |
| 字体 | 正文用「思源宋体」，标题用「方正清刻本悦宋」或「霞鹜文楷」 |
| 转场 | 水墨晕染/毛笔横扫效果；功能模块之间使用简洁的淡入淡出 |
| 背景音乐 | 古琴/琵琶轻音乐（推荐曲目风格：空灵、不抢戏） |
| 鼠标光标 | 使用放大高亮圈或激光笔效果（推荐工具：Presentify / ScreenBrush） |

### 录制工具推荐

| 用途 | 推荐工具 |
|------|---------|
| 屏幕录制 | OBS Studio（免费） / ScreenFlow（Mac） |
| 后期剪辑 | DaVinci Resolve（免费）/ 剪映专业版 |
